# R Script Writing Standards

This Codex Skill standardizes R script generation and review for scientific data analysis projects.

It follows a workflow-oriented structure inspired by mature Markdown skill repositories:

- `SKILL.md` is the main entrypoint and scenario router.
- `workflows/` contains task-specific procedures.
- `references/` contains style, reproducibility, and review rules.
- `templates/` contains reusable script skeletons.
- `examples/` contains concrete example scripts.

## What It Emphasizes

- clear analysis pipeline sections
- readable object names
- useful but restrained comments
- local function definitions only when needed
- explicit input and output organization
- reproducible result export
- assumptions and user-editable parameters clearly marked

## Usage

Ask Codex to use `$r-script-writing-standards` when drafting, revising, or reviewing an R analysis script.
